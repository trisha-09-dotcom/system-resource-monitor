# System Resource Monitor 🖥️

A cloud-native monitoring utility for tracking CPU and memory usage in real-time.
<img width="1920" height="1080" alt="Screenshot (28)" src="https://github.com/user-attachments/assets/b30c1ffc-9957-459f-981e-1329c0ff3ded" />


### 🛠 Tech Stack
* **Backend:** Python (psutil)
* **Web Framework:** Flask
* **Infrastructure:** Docker (Containerized for environment consistency)

### 🚀 Key Technical Achievement
* Developed a real-time system tracking backend.
* **Containerized the application using Docker**, ensuring the environment is identical across local development and cloud deployment environments.

### 📋 How to run
1. Build the container: `docker build -t system-monitor .`
2. Run the container: `docker run -p 5000:5000 system-monitor`# system-resource-monitor
